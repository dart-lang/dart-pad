# Counter

The standard Flutter counter application demonstrating state management with a `StatefulWidget`.

## How it works

- `CounterApp` sets up a `MaterialApp` with Material 3 styling.
- `CounterPage` manages a counter integer in its state (`_counter`).
- Tapping the floating action button triggers `_incrementCounter`, which calls `setState()` to rebuild the UI with the updated value.

Press **Run** to launch the Flutter app in the preview panel.
