# Flame game

A simplified 2D Brick Breaker arcade game built using the [Flame game engine](https://flame-engine.org/) for Flutter.

## How it works

- Uses Flame''s component system (`BrickBreaker`, `PlayArea`, `Ball`, `Paddle`, and `Brick`) with collision detection and physics simulation.
- Embedded into Flutter using Flame''s `GameWidget`.

To learn how to build a full version of this game step by step, check out the [Flutter Brick Breaker codelab](https://flutter.dev/to/brick-breaker).

Press **Run** to start the game in the preview panel.
